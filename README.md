# 시그니처클래스 교육 자료실

강의 영상(YouTube)과 교육자료(구글드라이브)를 모아 보는 사이트입니다.

- 홈: `index.html` — 강의 카드 목록
- 강의 페이지: `index.html?v=유튜브영상ID` — 영상 + 교육자료 바로 다운로드
- 관리자: `admin.html` — 강의 추가·수정 후 **저장**하면 `data/videos.json`이 바뀌고 1분 안에 사이트에 반영됩니다.

관리자 첫 접속 때 GitHub 토큰(이 저장소 Contents 읽기·쓰기 권한)과 Google API 키를 넣으면 브라우저에 기억됩니다. 토큰과 키는 이 저장소 코드에 넣지 마세요.
